# Project Setup Notes

## ⚠️ Important Notice

Due to GitHub storage limitations, not all files are included in this repository.

## 📁 Missing Data Folder

To run this project properly, you need to manually add a `data/` folder at the root of the project directory.

This folder should contain all required datasets and resources used in the notebook.

## 🗺️ Maps

Some large files (maps) are not hosted on GitHub because of size restrictions.

You can see them from the following link:

👉 [https://perso.ens-lyon.fr/perig.montfort/maps/roundabouts.html]

After downloading, please place the files inside the `data/` folder.

## ✅ Summary

* Create a `data/` folder in the project root
* Download the required files from the link in the notebook
* Place them inside the `data/` folder
* Then run the notebook normally
